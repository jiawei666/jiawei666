## Projects

### Rambo

**A personal AI agent that lives on your Mac.**<br>
`2026.10.31` · `Electron` · `React` · `TypeScript` · `Codex App Server`

[![GitHub](https://img.shields.io/badge/GitHub-Rambo-181717?style=flat-square&logo=github)](https://github.com/jiawei666/Rambo)
[![Latest Release](https://img.shields.io/github/v/release/jiawei666/Rambo?style=flat-square&label=release)](https://github.com/jiawei666/Rambo/releases/latest)
![Platform](https://img.shields.io/badge/platform-macOS%20arm64-111111?style=flat-square)

- **Local-first by design** — bots, chats, routines, settings, and memory stay on the machine in an isolated Codex Home.
- **Multiple Bots, one workspace** — each Bot keeps its own model, context, Skills, MCP servers, Apps, and Plugins, while still being able to work together in group chat.
- **An agent that acts** — routines, email, WeChat, computer and browser automation, voice, and local files all feed back into the same conversation.

### wecode

**Use local Codex from WeChat.**<br>
`2026.10.28` · `TypeScript` · `Node.js` · `Codex App Server` · `微信 iLink`

[![GitHub](https://img.shields.io/badge/GitHub-wecode-181717?style=flat-square&logo=github)](https://github.com/jiawei666/wecode)
[![npm](https://img.shields.io/npm/v/%40jiawei666%2Fwecode?style=flat-square&logo=npm&label=npm)](https://www.npmjs.com/package/@jiawei666/wecode)
![Node.js](https://img.shields.io/badge/Node.js-%E2%89%A522-339933?style=flat-square&logo=node.js&logoColor=white)

- **Native sessions** — Codex App Server owns the real thread history; wecode only stores local bindings and runtime state.
- **Made for mobile input** — send text, images, or files from WeChat and continue the same Codex conversation on the machine.
- **Long answers fit a phone** — live typing status, session switching by natural language, and temporary mobile-friendly share pages.

[Explore wecode →](https://github.com/jiawei666/wecode) · [npm](https://www.npmjs.com/package/@jiawei666/wecode)

### CODESK

**A three-pane terminal workspace for Codex.**<br>
`2026.10.25` · `Rust` · `Ratatui` · `PTY` · `Codex App Server`

[![npm](https://img.shields.io/npm/v/%40jiawei666%2Fcodesk?style=flat-square&logo=npm&label=npm)](https://www.npmjs.com/package/@jiawei666/codesk)
![Rust](https://img.shields.io/badge/Rust-2024%20edition-000000?style=flat-square&logo=rust&logoColor=white)
![Platform](https://img.shields.io/badge/platform-macOS%20%7C%20Linux%20%7C%20Windows-111111?style=flat-square)

- **Native Codex, not a wrapper** — a PTY hosts the installed Codex CLI with its original input, colors, approvals, and mouse protocol.
- **Sessions, files, and Git in one window** — manage project threads on the left, work with Codex in the center, and inspect files and diffs on the right.
- **Built for real repositories** — async ripgrep search, semantic navigation, Git-aware previews, and a workspace-scoped editor with explicit safety limits.

[View on npm →](https://www.npmjs.com/package/@jiawei666/codesk)
